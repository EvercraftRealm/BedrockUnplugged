# Changelog

## 1.0.0

- Added persistent simulated-player ghosts for Realms and Bedrock Dedicated Server.
- Added safe inventory, equipment, selected-slot, and XP transfer with persistent escrow recovery.
- Added automatic restoration after world and server restarts.
- Added configurable command and automatic-AFK unplugging.
- Added configurable durations, damage immunity, invisibility, and name colors.
- Added operator controls for managing active, removed, and dead unplugs.
- Added `/unplug`, `/afk`, and `/unplugadmin` commands without requiring cheats.
